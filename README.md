# CodeStoryMIK – DSA in Java

My Java solutions to DSA problems I'm solving while learning from the **[codestorywithMIK](https://www.youtube.com/@codestorywithMIK)** YouTube channel.

This repo is a record of my daily practice and progress toward mastering Data Structures & Algorithms and cracking coding interviews.

## 📂 Repository Structure

| Folder | Topic |
|--------|-------|
| [`Array_1D_&_2D`](./Array_1D_&_2D) | 1D and 2D array problems |
| [`Binary_Lifting`](./Binary_Lifting) | Binary lifting technique (LCA, k-th ancestor) |
| [`DP_Concpts`](./DP_Concpts) | Dynamic programming concepts and problems |
| [`Segment_Tree_Concepts`](./Segment_Tree_Concepts) | Segment tree concepts and range queries |
| [`Easy`](./Easy) | Easy-level problems |
| [`CodeStoryWithMIK`](./CodeStoryWithMIK) | Other problems from the channel |

## 🛠️ Tech Stack

- **Language:** Java
- **IDE:** Eclipse

## ▶️ How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/guruprasad22gp/CodeStoryMIK.git
   ```
2. Open the folder in Eclipse (or any Java IDE).
3. Open any solution file and run it.
